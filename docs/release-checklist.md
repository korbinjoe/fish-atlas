## 专家复核怎么收尾

使用 [review-queue.csv](review-queue.csv)，逐条填写审核人、日期、原始来源、适用鱼种／品系、是否涉及自然环境或长期饲养建议。数值发生冲突时保留来源差异，不合并极值。重点复核七彩神仙分类及缺失水质、旧学名对应、人工品系照片、咬鳍／捕食触发范围。规则集是初步筛查，没有覆盖全部配对的安全性。

## 真实手机怎么验收

记录手机型号、系统、浏览器、DPR、网络；冷启动探索页和图鉴页，连续拖动地球并切换区域，确认不误开鱼种。输入鱼缸、调整数量、保存并恢复规划；打开海水图鉴，放大缩小并关闭详情，检查焦点、滚动与控件遮挡。记录首屏、持续交互帧耗时和发热情况，按技术方案预算验收。不以桌面模拟的 60 FPS 作为实机通过依据。

## 数据更新

日常部署仅运行 `npm ci && npm run build`，不会访问第三方数据接口。更新来源资料是独立的人工触发流程；先保留发布版本，再运行采集和编辑脚本，核对变更后执行校验与浏览器测试。GBIF 出错时保留旧快照；不把新采集、未复核的记录直接称为专家审核数据。
