# 鱼缸规划走查与改版

走查范围：选择入门方案和尺寸、查找并加入鱼、查看数量与混养提醒。2026-10-12 在本地预览页以手机、1280 × 800 和 1920 × 960 桌面视口实际操作，截图均为本次走查捕获。

| 步骤 | 原状态与问题 | 改版后状态 |
| --- | --- | --- |
| 1. 定一个起点 | [原首屏](01-before-start.png)、[原尺寸设置](02-before-size.png)：选鱼入口被方案说明、重复提示、尺寸卡和全部数字输入推到几屏之后；新手难以判断哪些数字必须自己填。 | [新首屏](06-after-start.png)、[新桌面首屏](10-after-desktop-start.png)：常见方案与尺寸先呈现；当前配置即时汇总；专业参数和开缸依据在可展开区，另有“开始选鱼”。良好。 |
| 2. 挑鱼 | [原选鱼页](04-before-choose.png)：单张鱼卡占据大半屏，一次只能比较很少鱼种；后来改为横向列表后，又浪费了宽屏空间且鱼照片过小。 | [桌面卡片](14-card-desktop-first-screen.png)、[聚焦后的手机卡片](15-focused-fish-card-mobile.png)：图片占据卡片上半部；宽屏四列、较窄桌面两列、手机单列。卡片只显示缸长、水温、当前设置的优先提醒和加入操作；点击图片或鱼名后，在详情查看完整核对结果与来源。首批 12 种，可继续加载。良好。 |
| 3. 核对规划 | [原加入后](05-before-added-no-feedback.png)：卡片变为“已加入”，但风险信息在已经滚出的上方，当前视野看不到下一步。 | [手机加入后](08-after-added.png)显示已选数和提醒，可点“查看规划”到达[风险详情](09-after-review.png)；桌面在[右侧规划栏](11-after-desktop-added.png)直接反馈。良好。 |

仍需留意：部分辅助说明文字较小，截图只能判断可见布局和操作结果，不能据此宣称已满足全部无障碍标准；键盘、屏幕阅读器和实际中文输入法体验需要继续按对应设备验证。示例水质不代表实测结果，混养判断仍以现有规则及其资料覆盖范围为限。

后续更新：有明确群养数量来源的鱼按下限加入规划，例如红绿灯 8 条；没有结构化数量建议的鱼仍按 1 条起步并提示核对。[手机规划数量](16-recommended-stock-mobile.png)展示数量输入与增减按钮，[详细参数控件](17-shadcn-fields-mobile.png)展示与原有深色主题一致的 shadcn/ui 输入和下拉。搜索停顿后自动更新，中文输入法组词期间保持输入框稳定。
