# Fish Atlas

**[公開サイトを開く](https://fish-atlas-korbinjoe.korbinzhao.chatgpt.site)** · ChatGPT Sitesで公開しています。

魚の写真図鑑、分類カタログ、水槽プランナーを、操作できる地球儀でつなぐアプリです。各魚の情報には、確認に使った資料と写真の出典を表示します。

初回アクセス時の表示言語は**英語**です。ヘッダーのメニューから **English、中文、Français、Deutsch、日本語**に切り替えられ、選択はブラウザーに保存されます。

![英語表示の Fish Atlas とインタラクティブな地球儀](docs/i18n-default-english.png)

## 主な機能

- **地球儀で探索**：回転、拡大・縮小、流域の選択、主要な河川や湖の表示に対応しています。
- **写真図鑑**：一般名、別名、学名で検索し、地域や水域の種類で絞り込めます。お気に入りの保存と、飼育参考情報がある魚の最大3種の比較もできます。
- **地球儀と連動する詳細表示**：写真を開くと地球儀の横に詳細が表示され、資料で確認した原産水域が強調されます。左右の矢印キーで絞り込み結果を順に見られます。
- **写真ビューアー**：写真の拡大・移動や魚種の切り替えに対応し、地球儀を見ながら閲覧できます。
- **分類カタログ**：GBIFの受容名、科、属を確認できます。写真のない魚も検索でき、科別フィルターとページ送りを備えています。
- **水槽プランナー**：水槽サイズ、推定水量、水質、飼育数を設定し、既知の条件の不一致やリスクを確認できます。ブラウザーへの保存と、プランを復元できる共有リンクに対応しています。
- **出典とフィードバック**：参考資料、写真のクレジット、情報の追加・訂正用のGitHubフォームを用意しています。

写真付きの467種すべてに、資料で確認した名前のある原産水域を関連付けています。分類カタログは分類情報を調べるためのもので、水槽で飼育できる魚の一覧ではありません。写真のない魚はカタログで検索できますが、写真図鑑には表示されません。

[第2回の未収録流域拡充](docs/blank-basin-expansion-2.md)では写真付きの88種を追加し、新規・既存種の資料で確認した原産分布に基づき、これまで未収録だった166流域に魚を関連付けました。主要520流域のうち376流域に確認済みの関連があり、144流域は写真付きの魚が未収録です。[第1回の拡充](docs/blank-basin-expansion.md)は過去のデータ記録として残しています。

## 起動方法

必要環境：互換性のある**Node.js 22.12以降**とnpm。

```bash
git clone https://github.com/korbinjoe/fish-atlas.git
cd fish-atlas
npm ci
npm run dev -- --port 4173
```

[http://127.0.0.1:4173](http://127.0.0.1:4173)を開いてください。データ、写真、地図の素材はリポジトリに含まれており、インストールやビルド時に資料を再収集する必要はありません。

本番用ビルドをローカルで確認する場合：

```bash
npm run build
npm run preview -- --port 4174
```

- [地球儀で探索](http://127.0.0.1:4174/#/explore)
- [写真図鑑](http://127.0.0.1:4174/#/atlas)
- [分類カタログ](http://127.0.0.1:4174/#/catalog)
- [水槽プランナー](http://127.0.0.1:4174/#/planner)

ビルド結果は`dist/`に出力されます。ハッシュルーティングと相対パスを使用するため、サブディレクトリを含む静的ホスティングに配置でき、ルーティング用の書き換え設定は不要です。

## 多言語表示

言語を切り替えると、ナビゲーション、フィルター、詳細、地名、比較、プランナーの表示が更新されます。選択は`fish-atlas:locale`に保存されます。保存機能が利用できない場合も、その訪問中は言語を切り替えられます。

飼育参考資料がある33種の主な説明や飼育上の注意は、5言語で表示できます。検索は表示言語にかかわらず、中国語名、英語名、収録済みの各言語名、別名、学名を対象にします。

学名、数値、著者、ライセンス、原文の引用は出典の内容を維持します。追加の434種に含まれる資料の抜粋は、すべてが翻訳されているわけではありません。中国語表示では中国語のGitHubフォーム、それ以外では英語のフォームを使用します。詳しくは[多言語実装の記録](docs/i18n.md)をご覧ください。

## データを読むときの注意

地球儀上の写真マーカーは、**資料に基づく原産水域の表示位置**です。実際の採集地点や、その種の自然分布全体を示すものではありません。GRDCの流域境界は地理的な背景情報であり、魚の分布境界ではありません。

GBIFの過去の観察記録は、自然分布の情報とは分けて表示しています。出典とライセンスを確認した26件を収録していますが、原産かどうかは不明です。地球儀はリアルタイム追跡を行いません。

水槽プランナーは、現在ある参考資料とルールに基づく初期確認を行います。混泳の安全性や、飼育可能な総数を保証するものではありません。未確認の値は不明のまま扱い、推奨数が表示されても、その水槽に収容できることを意味しません。

自然環境の水温を、そのまま飼育の設定値にはしません。淡水の総硬度dGH、アルカリ度dKH、海水の比重は区別します。専門家による確認と実機スマートフォンでの検証は今後の課題です。[公開・確認チェックリスト](docs/release-checklist.md)に範囲を記載しています。

## 開発と検証

React 19、TypeScript、Vite、Three.js、React Three Fiber、Drei、Zodを使用しています。解決済みの依存関係のバージョンは`package-lock.json`に記録しています。

```bash
npm run validate
npm test
npm run build
npx playwright install webkit
npm run test:e2e
npm run benchmark
```

ブラウザーテストは、ローカルのChromeとPlaywright WebKitを使い、4174番ポートの本番プレビューに接続します。デスクトップでの計測やタッチ操作のシミュレーションは、実機での検証の代わりにはなりません。`npm run catalog:refresh`は、ネットワーク経由でGBIFのスナップショットを更新するための任意の操作です。通常のビルドには必要ありません。

## 出典とライセンス

Wikimedia Commonsの写真は、画像ごとにライセンスとクレジットが異なり、同じライセンスでの共有が必要な写真もあります。Natural Earthの地理データはパブリックドメインです。GRDC／HydroSHEDSの流域データは、各出典の条件に従ったクレジットが必要です。GBIF Backboneの分類カタログはCC BY 4.0、収録した観察記録は収集処理で対応しているCC BYまたはCC0の条件に従います。

**FishBase 26.06の分布データはCC BY-NC 3.0**で、クレジットの表示と非営利利用の条件が適用されます。ツールのコードや写真のライセンスとは別です。再利用する前に、[出典とクレジット](public/ATTRIBUTION.md)および[追加写真のクレジット一覧](public/PHOTO_PROFILES_ATTRIBUTION.md)をご確認ください。写真が表示できない場合のイラストは、魚種の同定には使えません。
